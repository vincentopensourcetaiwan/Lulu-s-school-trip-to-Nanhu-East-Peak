# 鹿鹿走讀轉進南湖東峰 · GPX 路徑整合圖

2026.08.13–08.18，南湖群峰縱走 28 個 GPX 檔去重整合後的互動地圖，
再把 394 張現場照片按座標與時間掛回軌跡上。
6 天 · 60 公里 · 累積上升 9,681 公尺 · 最高 3,643 公尺。

## 照片圖層

- 橘色圓點為照片位置，點數字表示該處照片張數；點一下開大圖。
- 大圖下方顯示第幾天、拍攝時間、海拔、當日行程、照片分類。
- 左右方向鍵依時間順序切換照片，Esc 關閉；右上角「照」可開關圖層。
- 355 張用 EXIF GPS 座標定位；39 張沒有座標，改用拍攝時間對到 GPX 軌跡
  （大圖會標「時間定位」）；2 張兩者都缺，未上圖。
- 照片已縮到長邊 800px（約 31 MB），原檔請自行保存。

## 上傳到 GitHub Pages

1. 建一個新的 repository（設為 Public）。
2. 把這個資料夾裡的檔案上傳到 repo 根目錄，必須放在同一層：

   - `index.html`
   - `support.js`
   - `trip-data.js`（軌跡資料）
   - `photos.js`（照片座標與時間）
   - `photos/`（394 張照片，整個資料夾）
   - `trip.json`（備份，可不上傳）

3. 進 repo 的 **Settings → Pages**，Source 選 **Deploy from a branch**，
   Branch 選 `main` + `/ (root)`，按 Save。
4. 等一兩分鐘，網址是 `https://<你的帳號>.github.io/<repo 名稱>/`。

## 注意事項

- 直接用瀏覽器打開 `index.html`（file://）也能看，軌跡資料放在 `trip-data.js`。
- 需要連網：字體、Leaflet、地形圖磚都來自 CDN。
- 底圖為「魯地圖」（Rudy Map，台灣登山專用圖資：等高線、山徑、水源、營地）。
- 目前版面是桌機寬螢幕設計，建議 1000px 以上；手機版另外處理。
- GitHub 單一 repo 建議別超過 1 GB，這份約 31 MB，沒問題。
